# Redes y Comunicaciones

Material de estudio y prácticas resueltas de Redes y Comunicaciones (Facultad de Informática, UNLP), cursada 2026.

## Estructura

- `teoria/`: diapositivas organizadas por capa: introducción, aplicación, transporte, red y enlace.
- `practicas/`: resoluciones de las prácticas 1 a 9, por capa.
- `parciales/`: enunciados y modelos de parcial del primer semestre de 2026.
- `promocion/`: resúmenes y recopilación de parciales teóricos para la promoción.

## Temas

- Capa de aplicación: HTTP, DNS, correo electrónico, FTP
- Capa de transporte: UDP, TCP, control de errores y de congestión
- Capa de red: IPv4, subnetting y VLSM, NAT, DHCP, ICMP, IPv6, ruteo
- Capa de enlace: Ethernet, switching y ARP

---

Las resoluciones son propias y pueden tener errores. El material de cátedra (diapositivas, enunciados y parciales) pertenece a sus docentes y está incluido solo como referencia de estudio.
